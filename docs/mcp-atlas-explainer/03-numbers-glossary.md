# 数字词典

前面几页先讲这些东西是什么。这一页把关键数字收在一起。每个数字两句：是什么，不是什么。

来源有三类。论文指 arXiv 2602.00933，统计的是全量 1,000 题，除非另写。公开仓指 GitHub 上的 `scaleapi/mcp-atlas`。公开 500 实测指 2026-09-27 对 Hugging Face 上那份 parquet 的计数，一共 500 行。提交号、修订号和数法写在 [99-evidence.md](99-evidence.md)。

论文和数据集卡片有时各写各的。两句都留着，因为它们量的常常不是同一件事。

## 题有多少

**1,000。** 是什么：论文里的全量题数，公开的一半加上不公开的一半。不是什么：不是 Hugging Face 文件里的行数。

**500（公开）。** 是什么：数据集卡片写的样本数，parquet 数出来也是 500 行。不是什么：不是全量，另一半不在这个文件里。

**500（不公开）。** 是什么：论文留下、不随数据集发布的另一半。不是什么：不是「文件里有、只是脚本没去读」的隐藏行。

**24。** 是什么：每道公开题的 `TASK` 题号长度，500 行都是 24 个字符，卡片也这样描述。不是什么：不是工具个数。

## 程序和接口有多少

**36。** 是什么：`mcp_server_template.json` 里要启动的 MCP 程序个数，README 和论文也写 36 个 server。不是什么：不是工具个数，也不是早期模板里的 45。一个程序下面有很多接口。

**45。** 是什么：2025-12-03 那版模板里的 MCP server 个数。不是什么：不是现在要启动的个数。2025-12-15 删掉 9 个之后，模板、README 和论文说的都是 36。提交号在证据页。

**307。** 是什么：README 所链 gist 里的接口目录总数。那个文件有 36 个程序标题，标题旁的个数加起来是 307，列表项也是 307 条。不是什么：不是每道题启用的接口数，也不是 2026-09-27 对镜像 `1.2.7` 现场调用 `/list-tools` 的结果。发布 1.2.7 的提交写，exa 的新版本还会多暴露 `exa_web_fetch_exa`，gist 里 exa 仍只列 1 个工具。容器没有在这次核对里启动。gist 的更新时间是 2025-12-18，早于代码提交。

**220。** 是什么：论文说的「任务里用到的不同工具」，数据集卡片也写公开子集使用 220 个工具。把公开 500 行的 `ENABLED_TOOLS` 名字合并，不同字符串正好是 220 个。不是什么：不是 gist 那份 307 的安装目录，也不能拿去减 307。307 减 220 得 87，这个 87 对不上任何一类工具。220 里有 25 个名字，当前模板已经没有对应进程。

这 25 个的前缀是 `anili` 12 个，`balldontlie` 2 个，`f1-mcp-server` 8 个，`rijksmuseum-server` 3 个。它们出现在 85 道题的允许名单里，参考调用记录里一次都没有。这 4 个前缀来自已经从模板删掉的 server，不是第 37 到第 40 个正在运行的进程。`balldontlie-mcp` 只是镜像里 `/data/repos` 下的一份仓库。

去掉这 25 个，前缀对得上当前 36 个进程的是 195 个。195 里有 194 个在 gist 的 307 条里。清单没有、题面却有的一个名字是 `clinicaltrialsgov-mcp-server_clinicaltrials_search_studies`。公开允许名单和 gist 的交集是 194。gist 里有 113 个名字从未进入公开允许名单。113 等于 307 减 194，不等于 307 减 220。

**195、194、113、106、25、85。** 是什么：上面这几句的计数。195 是去掉模板外名字之后还对得上 36 个进程的题面工具。194 是公开名单与 gist 的交集。113 是只在 gist 里。106 是公开参考调用真正用过的不同工具。25 是名单里、模板外的名字。85 是出现过这些模板外名字的题数。公开参考调用用到的程序前缀，正好是模板里的 36 个；那 106 个工具名都在 gist 里。不是什么：不是另一套 server 总数。运行中的程序仍按模板的 36 个来理解。106 也不是模型考试时只能用的工具数，模型看见的是每一题的候选名单。

**1 和 35。** 是什么：gist 里单个程序最少和最多的接口数。calculator、fetch、e2b-server、exa、mcp-server-code-runner 各有 1 个。twelvedata 有 35 个。github 有 33 个，desktop-commander 有 21 个，filesystem 有 14 个。不是什么：不是某一道题里启用了这么多个，也不是「从 1 到 35 每个整数都有一个程序」。

**20、11、5。** 是什么：不需要密钥、只需要密钥、需要密钥还要准备数据，三类程序的个数，加起来是 36。不是什么：不是题数，也不是接口数。不需要密钥也不等于这个程序断网就能完成它的全部动作。名单在 [06-network-and-keys.md](06-network-and-keys.md)。

**8 和 12。** 是什么：那 20 个里，按模板只在容器内计算、读文件或记笔记的个数，以及一被调用就会匿名访问外网的个数。12 等于 20 减 8。不是什么：8 不是「绝对不会产生网络包」。`mcp-code-executor` 和 `mcp-server-code-runner` 如果模型写出了带网页请求的代码，那段代码仍可能出网。12 不是 12 个容器。

**28。** 是什么：调用后会离开本机的 server 个数，12 个匿名加上 16 个带着密钥或账号。16 是 11 加 5。不是什么：不是 28 个镜像，也不是每道题会打 28 个网站。一道题的候选名单通常只涉及其中几个。

## 一道题看见多少

论文讲的是全量 1,000 题。公开文件上能数的是那 500 行。两套都写在这里。

**6 到 37，均值 15.2。** 是什么：论文说的，一道题暴露给模型的工具个数。不是什么：不是 307，也不是 220。那两个是全局目录或全局并集。

**7 到 37，均值 15.196，中位数 15。** 是什么：公开 500 行里 `ENABLED_TOOLS` 的长度，总和 7598，除以 500 得 15.196。四舍五入到两位小数是 15.20，和论文印的 15.2 相同。不是什么：下界不是论文写的 6。公开文件里最小是 7。文件里看不到那道「只有 6 个工具」的题，这里也不推测它在不在未公开的一半。

**2 到 8，均值 4.1。** 是什么：论文说的，其中解题真正需要的工具个数。不是什么：不是模型看见的整份名单。名单里其余的是干扰项。

**2 到 8，均值 4.11。** 是什么：公开 500 行里，参考调用记录出现过的不同工具名个数，总和 2055，除以 500 得 4.11。不是什么：不是允许名单的长度。有 4 道题的记录里出现了该题允许名单之外的名字，所以「记录里的工具全都在名单里」在公开文件上不是每一行都成立。这 4 道题的题号在 [99-evidence.md](99-evidence.md)。

**均值 11.1。** 是什么：论文说的，每题干扰项个数，也就是看见的名单减去真正要用的那些。不是什么：不是随便塞进来的一批无关网址。

**2 到 33，均值 11.094，中位数 10。** 是什么：公开 500 行里，允许名单去掉参考调用里出现过的名字之后还剩多少，总和 5547，除以 500 得 11.094。不是什么：因为有上面那 4 道例外题，这个均值不等于「15.196 减去 4.11」。

**10 到 25，以及 3 到 6。** 是什么：数据集卡片上的两句说明，分别说每题暴露 10 到 25 个工具、每题 3 到 6 次调用。不是什么：不是公开 parquet 的实际范围。允许名单的长度是 7 到 37。参考调用的条数是 3 到 17，总和 2423，均值 4.846。读文件时以文件为准，卡片原句仍留着，避免以后对不上。

**均值 9.8。** 是什么：论文说的，参考调用有多少步。不是什么：不是公开 500 的调用条数。公开文件把轨迹里的 `tool_calls` 逐条数，均值是 4.846。

**98.6%。** 是什么：论文说的，全量里需要至少两个程序配合的题的比例。论文还写 51.7% 恰好两个，38.2% 三个，8.7% 四个或更多，平均 2.55 个程序。不是什么：不是公开 500 的比例。

**5、296、168、29、2。** 是什么：公开 500 的参考调用里，用到 1 个、2 个、3 个、4 个、5 个程序的题数。至少两个程序的是 495 道。不是什么：这组计数不替换论文的 98.6%。

## 怎样算分，循环跑多久

**0.75。** 是什么：论文主分析的通过线，事实句平均分达到 0.75 算通过；低于 0.75 才做失败归类。不是什么：不是工具调用的正确率。

**0.50 和 0.75。** 是什么：公开评分脚本输出里的两档通过率，代码里的字段是 `pass_rate_0.50` 和 `pass_rate_0.75`。不是什么：0.50 不是论文正文的主指标。论文附录 G 另外还列了 0.90 这一档。

**均值 4.7，范围 1 到 23。** 是什么：论文说的，每题事实句的条数。不是什么：不是公开 500 的均值。

**499 行，均值 3.91，最小 1，最大 23。** 是什么：公开文件里能用 Python `ast.literal_eval` 读成列表的 `GTFA_CLAIMS`，499 行的条数统计。不是什么：不是严格 JSON 的解析结果。题 `689cd6f8522029b7ad7b1fe5` 的字符串在代码围栏处没有闭合，没有算进这 499 行。

**11。** 是什么：失败归类的类别数，4 类调用、7 类理解。不是什么：不是 server 数，也不是通过线的个数。定义在 [01-what-is-mcp-atlas.md](01-what-is-mcp-atlas.md)。

**100。** 是什么：一道题默认最多多少次工具调用，命令行是 `--max-tool-calls`，论文附录 A 也把预算写成 100。不是什么：不是这一题允许看见的工具个数。

**256。** 是什么：一道题默认最多多少轮对话，命令行是 `--max-turns`。不是什么：不是工具调用次数。一轮里可以调用多次工具。

**5。** 是什么：`run_eval.py` 默认同时跑几道题，`--concurrency`。不是什么：不是 5 个 server。

**1800。** 是什么：单题 HTTP 等待的默认秒数，`--timeout`。不是什么：不是沙箱从启动到就绪要等多久。README 写沙箱启动要 1 分钟以上，环境目录的说明写大约 1 到 3 分钟。

**8 GB，建议 10 GB 以上。** 是什么：README 让 Docker 预留的内存。不是什么：不是模型推理要用的显存。沙箱 Dockerfile 没有 GPU 安装步骤。

**82.2%。** 是什么：论文图 1 里最高的那个通过率，分母是 20 个模型、全量 1,000 题、主评判、覆盖率至少 0.75。不是什么：不是公开 500 的复现分。这份说明没有重跑模型。

## 端口和版本标签

**3001。** 是什么：harness 的默认端口。不是什么：不是 MCP 子进程的端口，也不是上游网站的端口。

**1984。** 是什么：沙箱 HTTP 的端口。不是什么：不是 stdio，也不是模型端口。

**1.2.7。** 是什么：预构建沙箱镜像的标签 `ghcr.io/scaleapi/mcp-atlas:1.2.7`，Makefile 里的 `VERSION = 1.2.7`。公开标签列表里还有 `1.2.0` 到 `1.2.6` 和 `latest`，推荐用的是 `1.2.7`。不是什么：不是论文的版本，也不是 harness 变更记录里的 v2.0.0。列表里没有 `1.1` 或 `1.0`。

**v2.0.0。** 是什么：变更记录里「循环从 Python 改成 TypeScript」那一节的标题。不是什么：不是镜像标签。`ghcr.io/scaleapi/mcp-atlas` 的标签列表里没有 `v2.0.0`。
